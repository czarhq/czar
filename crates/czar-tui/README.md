# czar-tui

Terminal UI for monitoring Czar workflow runs and tasks.

Install with `cargo install czar-tui --locked`, then run `czar-tui --base-url http://127.0.0.1:4000`.

czar is a workflow orchestrator; it's an early preview. See the [main README](https://github.com/czarhq/czar#readme) for what it does and how to start.
