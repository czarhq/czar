# czar-web

Web UI and API server for Czar.

A building block of czar, used by `czar-cli`; most people install the command instead: `cargo install czar-cli --locked`.

czar is a workflow orchestrator; it's an early preview. See the [main README](https://github.com/czarhq/czar#readme) for what it does and how to start.
