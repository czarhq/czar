# czar-macros

Proc macros for Czar Rust task authoring.

Used through the `czar` crate; you don't need to add it yourself.

czar is a workflow orchestrator; it's an early preview. See the [main README](https://github.com/czarhq/czar#readme) for what it does and how to start.
