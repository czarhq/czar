# czar-worker

Stateless worker server for Czar compile/execute task paths.

Install with `cargo install czar-worker --locked`. See the remote workers docs in the repository.

czar is a workflow orchestrator; it's an early preview. See the [main README](https://github.com/czarhq/czar#readme) for what it does and how to start.
